\section{Kiểm thử hệ thống}

\subsection{Công cụ và quy trình}
Nhóm dùng \texttt{pytest} cho kiểm thử Python và Ruff cho lint, import và định dạng mã. Phần JavaScript của giao diện được kiểm thử bằng trình duyệt Chrome thật, vì Ruff không kiểm tra JavaScript. Môi trường chạy là Windows với Python 3.14, Node 24+ và Chrome/Edge.

Toàn bộ kiểm thử được gom vào một bộ chạy tập trung \texttt{p3.py check}, cho phép chọn từng nhóm (suite). Bộ chạy này có các cơ chế bảo đảm kết quả đáng tin cậy:
\begin{itemize}
    \item PASS chỉ khi nhóm được chọn thật sự chạy và hoàn tất.
    \item Mỗi lượt chạy có UUID riêng và lưu báo cáo JSON, log, JUnit và ảnh chụp trình duyệt, dữ liệu nhạy cảm (khóa, ticket) được loại khỏi báo cáo.
    \item Có thời hạn tổng cho mỗi lượt, và Windows Job Object dọn toàn bộ cây tiến trình do lượt chạy tạo ra.
    \item Kiểm thử dùng cổng ngẫu nhiên do hệ điều hành cấp, không dừng tiến trình nào có sẵn.
\end{itemize}

Quy trình CI trên GitHub Actions chạy trên Windows với Python 3.14.

Nhóm tích hợp bao phủ chat chung và riêng hai chiều, gửi file hai chiều kèm đối chiếu SHA-256, ACK, online/offline, kết nối lại, chat trong lúc file còn đang truyền, và ngắt kết nối giữa DATA, FIN, COMPLETE. Trong lượt nghiệm thu trình duyệt thật, các file Unicode được truyền với kích thước 8.388.608 byte, 262.147 byte, 28 byte (cùng tên, nội dung mới) và file rỗng 0 byte; hash của file tải về đều khớp. Một ca từ chối file và một ca ngắt kết nối khi người nhận đang chờ chấp nhận cũng đạt, không có trạng thái hoàn tất giả.

\subsection{Hạn chế của kiểm thử}
\begin{itemize}
    \item Mọi kiểm thử chạy trên localhost, trên Windows, chưa có kết quả trên mạng LAN nhiều máy.
    \item Chưa kiểm thử đĩa đầy và chưa đo hiệu năng (benchmark), kết quả tải chỉ cho biết các lượt đã chạy đạt, không cho biết tần suất lỗi.
    \item Nhóm tải và file lớn chạy riêng trên máy phát triển, không nằm trong CI mặc định.
\end{itemize}
